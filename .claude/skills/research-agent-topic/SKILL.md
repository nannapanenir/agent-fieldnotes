# Research an Agent Fieldnotes topic

1. Clarify the reader question and the technical claims the article needs to support.
2. Browse current sources when facts can change. Prefer official documentation and changelogs, standards bodies, original research, and security advisories.
3. Record the source title, publisher, URL, publication or update date when available, the claim it supports, and any limits in what it establishes.
4. Separate stable concepts from version-specific facts. For comparisons, use the same criteria for every option and state the evaluation date.
5. Flag conflicting sources or claims that lack primary evidence. Do not invent citations, benchmark results, quotes, or production experience.
6. Return a concise research brief with: reader question, key findings, recommended outline, source list, version/date caveats, and open questions.

Do not write the final article unless requested. Save article content only when the user explicitly asks to draft or update a Markdown file.
